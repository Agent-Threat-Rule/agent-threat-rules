# ATR -> OWASP Agentic Skills Top 10 (AST10) Mapping

> Generated by `scripts/generate-ast-crosswalk.py` from rule metadata; do not edit by hand. The method, the category -> AST join table and its rationale are in [crosswalks/atr-ast-crosswalk.md](crosswalks/atr-ast-crosswalk.md). CI runs `--check`, so this file cannot fall behind the rules.

OWASP AST10 is a separate framework from the OWASP Top 10 for Agentic Applications (ASI01-ASI10). ASI covers agent runtime threats; AST covers the skill supply chain and lifecycle. Several AST controls are process requirements that a detection rule cannot satisfy.
